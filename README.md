## Shared footer

Edit `footer.html` to update the footer. `npm run build` inserts it into each
HTML page and writes the complete static site to `dist/`. `npm start` serves
that built site locally, and the Playwright test command builds it before
running the tests. GitHub Pages deployment publishes the generated `dist/`
directory.
